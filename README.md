# 视觉小游戏乐园

给 3–5 岁、戴足矫眼镜的高度远视孩子玩的视觉训练小游戏（PWA，平板/手机浏览器即可使用）。
每天自动安排 5 个小游戏，覆盖“看得细 / 看得清 / 眼睛灵 / 手眼巧”四类，难度按孩子表现自动升降；配合戴镜打卡、休息提醒和每日时长上限，帮助养成规律戴镜的习惯。

## 重要声明

- **不能降低远视度数，不能代替戴镜和复查。** 本工具只用于戴镜状态下的近距离视觉功能训练和戴镜习惯养成，请遵医嘱戴镜，并按时去医院复查。
- 训练中如出现眼痛、头痛、恶心等不适，请立即停止并就医。
- 游戏中的等级和曲线只反映孩子在本游戏里的表现，不是医学检查结果。

## 运行

需要 Node.js 18 及以上。

```bash
npm install
npm run dev -- --host
```

电脑和平板连同一个 Wi-Fi，在平板浏览器打开 `http://<电脑IP>:5173`（电脑 IP 可用 `ipconfig` 查看）。

### 发布与“添加到主屏幕”

```bash
npm run build
```

把生成的 `dist/` 目录部署到任意 **HTTPS** 静态托管（如 GitHub Pages、Cloudflare Pages、Netlify 等），用平板打开网址后选择“添加到主屏幕”，之后可全屏、离线使用。

本仓库已配置 GitHub Actions（`.github/workflows/deploy.yml`）：推送到 `main` 后自动测试、构建并发布到 GitHub Pages，地址为 https://xiaoaotianya.github.io/hyperopia-app/ 。首次使用需在仓库 Settings → Pages → Build and deployment → Source 选择 **GitHub Actions**。
局域网 http 地址不能注册 Service Worker，所以无法离线或安装，只适合临时试玩。

其他命令：`npm test` 运行单元测试；`npm run preview` 本地预览构建结果。

## 第一次使用

1. 首页右上角点 **家长 🔒** 进入家长区。家长门是一道两位数加法题，答对后 10 分钟内不用再答。
2. **屏幕校准**：把一张银行卡贴在屏幕上，拖动矩形右边缘（或用滑块、± 按钮）调到和卡片一样宽，点“保存校准”。手机竖屏放不下长边时可以选“量短边”。不校准的话，图案大小只是粗略估计。
3. **设置**：填写孩子昵称、头像；按需要调整每日时长上限（默认 12 分钟）、观看距离（默认 400 毫米，约 40 厘米）、休息间隔（默认每 5 分钟休息 20 秒），也可以填写复查日期，临近时家长区会提醒。
4. 让孩子 **戴好眼镜**，距离屏幕约 **40 厘米**。每天第一次打开时由家长点“家长确认：戴好了”，然后进入“今天的游戏”。

## 游戏列表（18 个，4 类）

| 类别 | 游戏 | 玩法 |
| --- | --- | --- |
| 🔍 看得细 | 🐞 找小瓢虫 | 找出斑点数不一样的那只瓢虫 |
| | 🃏 双胞胎配对 | 找出两张一模一样的点点卡 |
| | 🧩 补缺口 | 选出能补上饼干缺口的那一块 |
| | 🐟 小鱼游哪边 | 中间的小鱼朝哪边游，就点哪个箭头（旁边有“陪游”小鱼） |
| | 🔦 小手电找东西 | 在热闹的画面里找出指定的小物件 |
| 🌫️ 看得清 | 🎈 条纹气球 | 点有淡淡条纹的气球（对比度逐级降低） |
| | ⭐ 雾里找星星 | 在慢慢飘动的雾里找出淡淡的星星 |
| | 🫧 泡泡条纹 | 泡泡里的条纹是竖的还是横的（高等级为斜向） |
| | 🌙 月光下的形状 | 认出夜空里很淡的形状是圆、方、心还是房子 |
| 👀 眼睛灵 | 🦋 追蝴蝶 | 蝴蝶在花朵周围出现，快点它 |
| | 🚂 小火车 | 车厢变成星星时点它 |
| | 🐹 打地鼠 | 只打戴帽子的地鼠 |
| | 🐸 青蛙跳荷叶 | 青蛙从左到右一片片跳，点它所在的荷叶，像读书一样换行 |
| ✋ 手眼巧 | ✏️ 送小兔回家 | 按住小兔沿小路拖回家，不要出界 |
| | ✨ 点亮小灯 | 记住小灯亮起的顺序，再按顺序点 |
| | 🧠 翻翻乐 | 记住卡片位置，翻出相同的一对 |
| | 🧩 影子配对 | 把小动物拖进和它形状一样的影子里 |
| | 🔷 照样子摆 | 照着上面的样子，在下面点亮相同的格子 |

每局约 2.5 分钟，结束得到一张贴纸；达到每日时长上限后当天锁定。家长区可查看戴镜打卡日历和每个游戏的进度曲线。

## 数据与隐私

所有数据（设置、训练记录、打卡、贴纸）只保存在本机浏览器的本地存储里，不上传任何服务器。清除浏览器数据或使用无痕模式会丢失记录，可在 家长区 → 设置 里导出 JSON 备份。

PWA 图标由 `node scripts/gen-icons.mjs` 生成（仅用 Node 内置模块）。
