# 视觉小游戏乐园

给 3–5 岁、戴足矫眼镜的高度远视孩子玩的视觉训练小游戏（PWA，平板/手机浏览器即可使用）。
每天自动安排 5 个小游戏，覆盖“看得细 / 看得清 / 眼睛灵 / 手眼巧”四类，难度按孩子表现自动升降；配合戴镜打卡、休息提醒和每日时长上限，帮助养成规律戴镜的习惯。

## 重要声明

- **不能降低远视度数，不能代替戴镜和复查。** 本工具只用于戴镜状态下的近距离视觉功能训练和戴镜习惯养成，请遵医嘱戴镜，并按时去医院复查。
- 训练中如出现眼痛、头痛、恶心等不适，请立即停止并就医。
- 游戏中的等级和曲线只反映孩子在本游戏里的表现，不是医学检查结果。

## 运行

需要 Node.js 18 及以上。

```bash
npm install
npm run dev -- --host
```

电脑和平板连同一个 Wi-Fi，在平板浏览器打开 `http://<电脑IP>:5173`（电脑 IP 可用 `ipconfig` 查看）。

### 发布与“添加到主屏幕”

```bash
npm run build
```

把生成的 `dist/` 目录部署到任意 **HTTPS** 静态托管（如 GitHub Pages、Cloudflare Pages、Netlify 等），用平板打开网址后选择“添加到主屏幕”，之后可全屏、离线使用。

本仓库已配置 GitHub Actions（`.github/workflows/deploy.yml`）：推送到 `main` 后自动测试、构建并发布到 GitHub Pages，地址为 https://xiaoaotianya.github.io/hyperopia-app/ 。首次使用需在仓库 Settings → Pages → Build and deployment → Source 选择 **GitHub Actions**。
局域网 http 地址不能注册 Service Worker，所以无法离线或安装，只适合临时试玩。

其他命令：`npm test` 运行单元测试；`npm run preview` 本地预览构建结果。

## 第一次使用

1. 首页右上角点 **家长 🔒** 进入家长区。家长门是一道两位数加法题，答对后 10 分钟内不用再答。
2. **屏幕校准**：把一张银行卡贴在屏幕上，拖动矩形右边缘（或用滑块、± 按钮）调到和卡片一样宽，点“保存校准”。手机竖屏放不下长边时可以选“量短边”。不校准的话，图案大小只是粗略估计。
3. **设置**：填写孩子昵称、头像；按需要调整每日时长上限（默认 12 分钟）、观看距离（默认 400 毫米，约 40 厘米）、休息间隔（默认每 5 分钟休息 20 秒），也可以填写复查日期，临近时家长区会提醒。
4. 让孩子 **戴好眼镜**，距离屏幕约 **40 厘米**。每天第一次打开时由家长点“家长确认：戴好了”，然后进入“今天的游戏”。

## 家庭视觉管理

除了小游戏，家长区还有一套在家就能做的视觉管理工具。家长区首页会把需要处理的事情列成提醒（红色是重要提醒，比如复查日期已过；黄色是建议尽快处理；灰色是一般提示）。

### 戴镜记录与小树

- 每天在家长区首页记录孩子今天的戴镜情况：**全天 / 大半天 / 少于一半 / 没戴**。全天和大半天算“达标”。
- 晚上 6 点以后，如果今天还没记录，孩子首页会出现一条“家长：记录今天戴镜情况”的小横幅，点它可以进入家长区。
- 忘了记？在“戴镜打卡”日历里可以补录或修改最近 7 天。
- 孩子首页有一棵**戴镜小树**：每个达标天长一片叶子，攒够 7 片开一朵花，30 片结一个果子。连续达标 3、7、14、30 天，孩子会得到“眼镜小勇士”贴纸。当天记错了改回来，不会重复发贴纸。

### 视力自测

用图形视标（苹果、房子、圆圈、方块）在家给孩子测近视力，每 2–4 周测一次，约 3–5 分钟。

1. **先做屏幕校准**（家长区 → 屏幕校准），否则视标大小不准，无法开始测试。
2. 在设置里填写孩子的**出生年月**，结果才能和同龄参考线对比。
3. 孩子**戴着平时的眼镜**，光线充足，坐稳后让眼睛离屏幕 **40 厘米**（用卷尺量，或剪一根 40 厘米长的绳子比一下）。
4. 先测右眼：用手掌或遮眼贴**轻轻挡住左眼**，别压眼睛，也别从指缝偷看；然后换眼测左眼。
5. 每只眼先练习 2 题。孩子说出图形名字或用手指，家长点对应的按钮；看不清就点“看不清”。中途切到别的应用会自动暂停，可以继续或重新开始，测一半退出不会保存。

结果页显示两只眼的小数视力、和上次相比的变化，以及是否需要重测或去医院。“视力自测”页可以看历史趋势。部分屏幕太小或分辨率低的设备测不到最好的几档，结果里会注明。

> **自测结果只是参考**，受光线、距离和孩子配合程度影响，不能代替医院检查。结果提示异常时请先重测；两次都异常，请带孩子去医院复查。

### 观察清单

- **每月观察清单**：每月填一次，约 2 分钟，按孩子最近一个月的日常表现回答“没有 / 有时 / 经常”。像“摘掉眼镜时眼睛往内偏（对眼）”这类需要留意的信号，首页会提醒尽快咨询医生。
- **随时记录**：平时发现异常（比如歪头看东西、眯眼），点“我发现了异常”随手记下。
- 页面里有“怎么在家看眼位”的简单说明。

### 复查档案与日历

- 每次去医院复查后，把验光结果记下来：复查日期、是否散瞳、两眼的球镜 / 柱镜 / 轴位、矫正视力、眼位、医生建议和下次复查日期。
- 和上一次相比，度数变化达到 0.50D 会标出来，方便和医生沟通。
- 点“📅 加入日历”会下载一个日历文件，打开后可以加入手机日历，复查前一天提醒。复查前 14 天起，家长区首页也会提醒。

### 医生报告

家长区 → 医生报告，会把近 1 / 3 / 6 个月的戴镜情况、视力自测、观察记录、训练概况和当前处方整理成一页，点“打印 / 保存为 PDF”即可打印或另存为 PDF，复查时带给医生看。在微信等不能打印的地方打开时，可以截图保存。

### 备份恢复与添加到主屏幕

- **导出备份**：家长区 → 设置 → 数据安全 → 导出备份，会下载一个 `视觉乐园备份-日期.json` 文件，请保存到网盘或发给自己。超过 30 天没备份，首页会提醒。
- **从备份恢复**：换设备或数据丢失时，在同一位置点“从备份恢复”，选择备份文件，确认后本机数据会被备份内容替换。选错文件不会改动当前数据。
- **添加到主屏幕**：iPhone / iPad 上的 Safari 会在长时间不打开后清理网页数据。请在 Safari 中点“分享”→“添加到主屏幕”，以后从主屏幕图标打开，数据更安全。应用打开时也会向浏览器申请“防清理保护”，结果显示在设置页。

## 数据与隐私

所有数据（设置、训练记录、戴镜记录、视力自测、观察记录、复查档案、贴纸）只保存在**这台设备**的浏览器本地存储里，不上传任何服务器，换设备不会自动同步。清除浏览器数据或使用无痕模式会丢失记录，请定期在 家长区 → 设置 里导出备份，需要时再从备份恢复。

PWA 图标由 `node scripts/gen-icons.mjs` 生成（仅用 Node 内置模块）。
