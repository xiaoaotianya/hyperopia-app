# P0：远视儿童家庭视觉管理 · 设计文档

日期：2026-10-29
状态：待用户审阅
基于：`2026-10-29-hyperopia-vision-games-design.md`（训练部分不变）

## 1. 背景与目标

孩子 3–5 岁，双眼约 +7.00D，足矫戴镜，目前无弱视、无斜视。对高度远视儿童，长期效果主要取决于两件事：

1. **坚持戴镜**：这是最主要的"治疗"。
2. **尽早发现变化**：例如出现弱视（两眼视力拉开差距、视力不达标）或调节性内斜视。

所以 P0 的目标，是把应用从"训练工具"升级为"家庭视觉管理工具"。新增 4 个功能：

| # | 功能 | 要解决的问题 |
|---|---|---|
| 1 | 戴镜依从性 | 记录全天实际戴镜情况，奖励与戴镜挂钩 |
| 2 | 左右眼近视力自测 | 每 2–4 周在家自测一次，看趋势，异常时提示复查 |
| 3 | 异常信号观察 | 每月一份观察清单，及早发现斜视等信号 |
| 4 | 复查与处方档案 | 记录每次复查，提醒下次复查，生成给医生看的报告 |

另外补 3 个数据安全小功能：导入备份、持久化存储、复查日期加入日历。

**约束：**
- 纯前端实现，不需要后端。数据存在本机 localStorage，延续现有 `store`。
- 所有"提示"都只是建议就医，不作诊断。页面措辞统一为"建议复查 / 建议咨询医生"。
- 功能 1–4 都放在家长区（受家长门保护），孩子端只增加戴镜奖励的展示。

**本期不做：** 摄像头检测是否戴镜或测距离（P1）、云同步、推送通知、拍眼位照片。

## 2. 功能 1：戴镜依从性

### 2.1 每日戴镜记录
- 家长给当天打一个档位：
  - `full` 全天（几乎一直戴着）
  - `most` 大半天
  - `less` 少于一半
  - `none` 没戴
- 记录入口：
  - **家长区首页**的"今天戴镜情况"卡片，4 个大按钮，一次点击即完成；
  - **孩子端首页**在 18:00 以后显示一条小横幅"家长：记录今天戴镜情况 👓"，点击后经过家长门进入家长区首页；
  - **戴镜打卡日历**里点任意一天，可以补录或修改（只允许最近 7 天）。
- 原有的"开始训练前确认戴好了"保留不变，含义是"训练时戴着眼镜"。如果当天没有补录全天档位，这一天在统计里按"未记录"处理，不会自动算作全天。

### 2.2 统计与展示
- **达标天**：档位为 `full` 或 `most` 的日子。
- **连续达标天数**：从今天往前数（今天还没记录的话，从昨天开始数）。
- 打卡日历用 4 种颜色区分档位，"未记录"显示为空心。
- **本周小结**：家长区首页显示"本周 X/7 天达标"。如果近 7 天达标少于 5 天，进入提醒列表（见第 6 节）。

### 2.3 孩子端奖励：戴镜小树 🌱
- 孩子首页增加一棵"戴镜小树"。每个达标天长一片叶子，满 7 片开一朵花，满 30 片结一个果子，用 CSS 或 SVG 绘制。
- 连续达标 3、7、14、30 天时，发一枚专属贴纸（"眼镜小勇士"系列），并语音祝贺。
- 小树只和戴镜挂钩，和训练无关。没戴镜不会"掉叶子"，只是不长新叶，不做惩罚。

## 3. 功能 2：左右眼近视力自测

### 3.1 视标与尺寸
- 视标：4 种 LEA 风格图形（苹果、房子、圆形、方形），由代码绘制。
- 拥挤效应：视标四周加拥挤框（间距为 0.5 个视标宽、线宽为 1 个笔画宽）。
- 测试距离：固定 40cm，使用 `settings.viewingDistanceMm`，默认 400。
- 视力档位：logMAR 1.0、0.9 … 0.0，每档差 0.1，共 11 档。
- 视标高度 = 5 × MAR，单位角分，用 `arcminToPx` 换算成像素。
- 对应的小数视力：`10^(-logMAR)`，在界面上显示，例如 logMAR 0.3 = 0.5。

**设备下限：** 视标高度不足 10 个设备像素的档位，在这台设备上判定为"不可测"。测试的最小档位截止到可测的最好档，结果里注明"本设备最好只能测到 X"。

**前置条件：**
- 必须先完成屏幕校准（`calibration.pxPerMm` 不为空），否则引导去校准。
- 测试前显示"如何保持 40cm"：用卷尺或一根 40cm 长的绳子量一下，并配示意图。

### 3.2 测试流程（由家长主导，约 3–5 分钟）
1. **准备页**，提醒三件事：
   - 戴着眼镜测；
   - 光线充足、不反光；
   - 孩子坐稳，屏幕离眼睛 40cm。
2. **先测右眼**：家长用手掌或遮眼贴挡住左眼，页面上有示意图（"轻轻挡住，别压眼睛、别从指缝偷看"）。
3. **练习**：先用 logMAR 1.0 的大视标练 2 题，让孩子熟悉作答方式。孩子说出图形名称或用手指，由家长点下方对应的大按钮；孩子也可以自己点。另有一个"看不清"按钮，算作答错。
4. **正式测试**：
   - 起始档位：这只眼上次的结果再大 0.2；第一次测从 0.7 开始。
   - 每档出 3 题，答对 2 题及以上算通过。
   - 通过后进入更小一档；不通过就回到更大一档。
   - 结果取通过的最小档。连最大档 1.0 都不通过，记为"> 1.0"。
   - 每档、每题都是随机的视标，不会连续两题相同。
5. 测完右眼后，提示换眼，**再测左眼**，流程相同。
6. **结果页**：
   - 两眼的小数视力和 logMAR；
   - 与上次相比是进步、持平还是下降；
   - 提示语（规则见 3.3）；
   - 如果需要，给出"建议 1 周内重测一次"的按钮。

整个测试中，孩子可以随时暂停，测一半退出则不保存。

### 3.3 判定与提示
年龄参考线采用 AAPOS 儿童视力筛查转诊标准，按月龄判断。这一标准本身针对远视力，这里只作参考，在界面上说明：

| 月龄 | 单眼未达到以下视力时提示 |
|---|---|
| 36–47 个月 | 0.4（logMAR 0.4，即 20/50） |
| 48–59 个月 | 0.5（logMAR 0.3，即 20/40） |
| ≥ 60 个月 | 0.63（logMAR 0.2，即 20/32） |

以下任一情况算"本次异常"：
- 任一只眼差于年龄参考线；
- 两眼相差 ≥ 2 档（logMAR 差 ≥ 0.2）；
- 任一只眼比上次下降 ≥ 2 档。

根据异常的次数给出不同提示：
- **第一次异常**：提示"孩子可能累了或没配合好，建议 1 周内重测一次"。
- **14 天内连续两次异常**：提示"建议近期带孩子去医院复查"，并写入提醒列表。
- **3 岁以下**（需要填写出生年月）：不使用年龄参考线，只看两眼差和趋势。

### 3.4 趋势
- 家长区的"视力自测"页显示左右两条折线：横轴是日期，纵轴是小数视力（按 logMAR 等距排列）。
- 下方是历史列表，每次测试可以展开看每档的作答明细。
- 自测提醒：距上次自测超过 28 天，进入提醒列表。

## 4. 功能 3：异常信号观察

### 4.1 每月观察清单
每月提示一次（距上次超过 30 天就进入提醒列表），家长约 2 分钟完成。每项回答"没有 / 有时 / 经常"：

1. 摘掉眼镜时，眼睛有没有往内偏（对眼）？
2. 戴着眼镜时，眼睛有没有偏斜？
3. 看东西时眯眼、歪头或侧着脸看？
4. 经常揉眼睛或说眼睛累？
5. 看书、看图时凑得很近？
6. 闭上或挡住一只眼才看东西？
7. 不愿意戴眼镜，或者摘镜后更愿意看近处？
8. 走路容易磕碰、拿东西够不准？

其中第 1、2、6 项是"重点信号"：
- 重点信号出现"有时"或"经常"：提示"建议近期咨询医生"，写入提醒列表。
- 其他项出现"经常"：提示"复查时可以告诉医生"，写入报告，但不进入提醒列表。

### 4.2 眼位小检查指引
- 清单页附一个"怎么看眼位"的图文指引：
  - 在约 50cm 处，用手电筒对着孩子的鼻梁照；
  - 看两个瞳孔上的小白光点是否都在瞳孔中央、是否对称；
  - 再用手遮住一只眼、移开，观察这只眼有没有移动。
- 页面上明确：家长观察只能发现明显的问题，看着正常也不能代替医院检查。

### 4.3 随时记录
- "我发现了异常"快捷入口：随时可以记一条，包含日期、对应清单项（可多选）和备注。
- 这些记录和月度清单一起显示在时间线上，并会写进报告。

## 5. 功能 4：复查与处方档案

### 5.1 复查记录字段
| 字段 | 说明 |
|---|---|
| 日期 | 必填 |
| 医院 / 医生 | 选填 |
| 是否散瞳验光 | 是 / 否 |
| 右眼 OD、左眼 OS | 球镜 SPH（-20 到 +20，步长 0.25）、柱镜 CYL（-6 到 +6）、轴位 AXIS（0–180）、矫正视力（小数或 logMAR） |
| 眼位检查结果 | 正常 / 内斜 / 外斜 / 其他 |
| 是否更换眼镜 | 是 / 否 |
| 医生建议 | 文本 |
| 下次复查日期 | 必填，提供"3 个月后 / 6 个月后"快捷按钮 |

填写要求：
- 度数用带步长的输入框，带正负号。
- 只有必填项填完才能保存。
- 球镜超过 ±20 时提示检查输入。

### 5.2 时间线展示
- 按日期倒序显示卡片，每张卡片包含两眼度数和矫正视力。
- 与上一次复查相比，度数变化 ≥ 0.50D 时高亮显示。
- 顶部显示"当前处方"，即最近一条记录。

### 5.3 复查提醒
- 下次复查日期取最近一条复查记录的 `nextDate`。如果还没有任何复查记录，使用原来的 `settings.recheckDate`（旧数据兼容）。
- 提醒时机：
  - 距下次复查 14 天内：进入提醒列表；
  - 已过期：标红提示；
  - 孩子端首页不显示复查提醒。
- **加入日历**：生成一个 `.ics` 文件，事件是"带孩子眼科复查"，全天事件，提前 1 天提醒。手机下载后可以导入系统日历。

### 5.4 给医生的报告
新增 `/parent/report` 页面，是一个可打印的单页 A4 报告。默认统计近 3 个月，可选 1、3、6 个月。

报告内容：
1. 孩子信息：昵称、出生年月、当前处方。
2. 戴镜依从性：达标天占比、各档位天数、每天一格的日历条。
3. 近视力自测：两眼的趋势表，以及最近 3 次的结果。
4. 观察记录：重点信号、"经常"项、随时记录的条目。
5. 训练概况：总训练天数和时长；四类能力的进步，用通俗的话描述，比如"能分辨的图案缩小了 x%"。
6. 免责声明：本报告由家长记录及家庭自测生成，仅供医生参考。

使用方式：点"打印 / 保存为 PDF"，调用 `window.print()`，用打印样式隐藏导航元素。

## 6. 家长区首页改版：提醒中心

家长区首页从"菜单列表"改为"仪表盘加菜单"，从上到下依次是：

1. **今天戴镜情况**：4 个档位按钮；已记录的显示档位，并可以修改。
2. **提醒列表**：由 `core/alerts.ts` 根据当前数据计算，按严重程度排序。每条提醒都带一个"去处理"按钮，跳到对应页面。提醒类型有：
   - 复查已过期（红色）；
   - 视力自测连续两次异常（红色）；
   - 观察清单出现重点信号（红色）；
   - 复查日期临近（黄色）；
   - 近 7 天戴镜达标少于 5 天（黄色）；
   - 视力自测超过 28 天没做（灰色）；
   - 观察清单超过 30 天没做（灰色）；
   - 超过 30 天没有备份（灰色）；
   - 尚未做屏幕校准（灰色）；
   - 原有的本地存储不可用、语音不可用提示（灰色）。
3. **概览卡片**：
   - 连续达标天数；
   - 最近一次自测结果；
   - 下次复查日期；
   - 本周训练分钟数。
4. **菜单**：戴镜打卡、视力自测、观察记录、复查档案、医生报告、训练进度、设置、屏幕校准、声明。

## 7. 数据安全

- **持久化存储**：应用启动时调用一次 `navigator.storage.persist()`（浏览器支持时），把结果记录到 `meta.persisted`。设置页显示"已开启防清理保护"或"浏览器未授予"。
- **导入备份**：设置页新增"从备份恢复"。
  - 选择 JSON 文件后先预览（备份日期、记录条数），确认后再覆盖当前数据；
  - 导入时走 `migrate`，兼容旧版本数据；
  - 格式不对时提示"不是有效的备份文件"，当前数据保持不变。
- **备份提醒**：
  - 导出时记录 `meta.lastBackupAt`；超过 30 天未导出，进入提醒列表。
  - 导出的文件名为 `视觉乐园备份-YYYY-MM-DD.json`。
- **引导添加到主屏幕**：在 iOS 上，如果不是从主屏幕打开的（不是 `display-mode: standalone`），在设置页和首次启动时提示"添加到主屏幕可以避免数据被浏览器清理"。

## 8. 数据模型（版本 v2）

存储键保持 `hyperopia.v1` 不变，避免丢失已有数据；数据内的 `version` 升级为 2。

```ts
type WearLevel = 'full' | 'most' | 'less' | 'none'

interface DayRecord {             // 新增 wear
  glassesOn: boolean; secondsTrained: number; gamesPlayed: string[]; plan: string[]
  wear?: WearLevel
}

interface AcuityTrial { logmar: number; symbol: string; answer: string | 'unseen'; correct: boolean }
interface EyeResult { logmar: number | null /* null = 劣于 1.0 */; trials: AcuityTrial[] }
interface AcuityTest {
  id: string; date: string; ageMonths: number | null
  distanceMm: number; pxPerMm: number; bestMeasurableLogmar: number
  od: EyeResult; os: EyeResult
  flags: ('below-age' | 'interocular' | 'decline')[]
}

type Freq = 'no' | 'sometimes' | 'often'
interface Checklist { id: string; date: string; answers: Record<string, Freq>; note: string }
interface Observation { id: string; date: string; items: string[]; note: string }

interface EyeRx { sph: number; cyl: number; axis: number; va: number | null /* 小数视力 */ }
interface Visit {
  id: string; date: string; hospital: string; cycloplegic: boolean
  od: EyeRx; os: EyeRx
  eyePosition: 'normal' | 'eso' | 'exo' | 'other'
  newGlasses: boolean; advice: string; nextDate: string
}

interface AppData {
  version: 2
  profile: { nickname: string; avatar: string; birthMonth: string | null /* YYYY-MM */ }
  // settings / calibration / games / days / stickers 同 v1
  acuityTests: AcuityTest[]
  checklists: Checklist[]
  observations: Observation[]
  visits: Visit[]
  meta: { lastBackupAt: string | null; persisted: boolean | null }
}
```

迁移规则：从 v1 迁移到 v2 时，新增字段补默认值，`profile.birthMonth` 为 null，其余数据原样保留。

## 10. 错误处理

- **自测中断**：页面切到后台时暂停；回来后提示"继续"还是"重新开始"。退出则不保存。
- **未校准、未填出生年月**：自测前分别引导去校准、去填写出生年月。不填出生年月也能测，只是不做年龄参考判断。
- **表单校验**：日期不能晚于今天（下次复查日期除外）；度数超出范围时提示。
- **导入失败**：当前数据不变，并提示失败原因。
- **打印**：浏览器不支持打印时，提示截图保存。

## 11. 测试

- **单元测试（Vitest）：**
  - wear：档位统计、连续天数（含今天未记录的情况）、小树计算；
  - acuity：
    - 视标尺寸：logMAR 0 在 40cm 处约 0.58mm；
    - 可测下限；
    - 阶梯流程：起始档、通过与回退、结果取值、最大档也不通过时的处理；
    - flags 判定；
  - ageNorms：月龄计算与三档参考线；
  - alerts：每种提醒的触发条件和边界（比如 14 天、28 天、30 天）；
